## 이 폴더가 하는 일

인역의 모든 매체(소설 표지·삽화, 웹툰, 애니, 게임 아트, 팬아트)가 **같은 세계로
보이게 하는** 최소한의 시각 규칙만 둔다. 개별 작품의 인물 외형, 분위기, 색 비중,
컷 단위 지시는 여기 두지 않는다. 그것은 각 작품의 제작 문서(`innyeok-studio`)에 남는다.

## 출처

전부 `innyeok-studio/docs/production/arc1-1-art-bible.md`(《침식 내성 들고 탐사 생활》
아크 1-1 작화 정본, studio 커밋 `b148f38` 기준)에서 **작품에 묶이지 않은 규칙만** 떼어 왔다.
원문의 규칙을 새로 바꾸지 않았고, 작품 전용으로 보이는 부분은 아래 표에 따라 제외했다.

## 공통으로 옮기지 않은 것 (작품별로 남김)

프로젝트 원칙상 **작품마다 분위기·비중이 다를 수 있고, 개별 작품 규칙을 IP 전체로
넓히지 않는다.** 그래서 아래는 studio 작화 정본에 남긴다.

| 항목 | 남기는 이유 |
|---|---|
| 7~7.5등신 성인 비례, "미성년 인상 금지" | 《하교 후, 선도를 걷는다》는 학원물이다. 비례·연령 인상은 작품마다 정한다 |
| 분위기 7규칙 (무채색+청록 하나, 젖어 있음, 파란 하늘 없음, 닳아 있음 등) | 아크 1-1의 톤이다. 2026-09-07 정정에서 이미 남육 노후 공간으로 범위를 좁혔다 |
