# 비주얼 작업 — 사용자 수정 기준

> 이슈 #6 후속. 기존 캐논 본문 변경 전 검토 문서.
> 아래 최신 지시가 이전 제안보다 우선한다. 이미지 파일은 이 PR에 포함되지 않으며 사용자 대화에 표시되었다.

## 최신 사용자 결정

1. 사슴: 사용자가 이미 좋다고 한 이전 시안 유지. 이후 제작한 매끈한 재형성 수정본으로 대체하지 않는다. 승인 원본을 특정해 앵커로 확보하기 전 추가 재제작하지 않는다.
2. 조명: 기본 청록이며 다른 색상으로 변경 가능. 색 변경 원리·등급·수치는 추가 확정하지 않는다.
3. 운용: 저레벨은 만지는 것으로 가능하며 고레벨은 만지지 않아도 가능. 정확한 LV 경계·사거리·조작 가능한 대상 범위는 미정. 그림의 2m 표시는 구도 예시일 뿐 설정 수치가 아니다.
4. 살아 있는 사람의 침식: 기존 기하 무늬 시안은 불채택. 무늬 없는 표면으로 수정했다. 이는 기존 erosion.md의 공통 패턴 지침과 조정이 필요한 사용자 수정이며, 다른 침식종의 무늬까지 일괄 제거한 것으로 해석하지 않는다.
5. 미래 분위기: 과도하게 돌출된 배관을 제거하고 매립 도관·통합 설비·정밀 외장·미래 건축 구조를 사용한다. 모든 지역의 기술 격차나 정비용 노출 부품까지 금지한 것은 아니다.
6. 침식 결정·잔편: 분리 소재와 운반 용기 시안 제작. 내부 형성 원리·두 용어의 관계는 계속 미정.

## 추가 선택 및 현재 작업

사용자는 수정된 ‘인역 미래형 영기공학’ 분위기를 좋다고 평가했다. 도시 방향을 유지하며 의복을 더 한국식으로 바꾸도록 요청했다. 고구려·신라·백제·고려·조선·현대 의복을 참고한 복수의 의복 시안을 제작한다. 개별 의상은 역사 복원물이 아니라 인역용 디자인 제안으로 구분한다.
