# 선협펑크 화풍 — 공통 규약

> 상태: 승격 후보. 표기 뜻은 [README](README.md#표기) 참조.
> 출처: studio `arc1-1-art-bible.md` §0 "화풍 — 선협펑크"(2026-09-04 전면 교체, 사용자 지시)와
> "분위기 규약 — 가져오지 않는 것".

## 1. 결합 원리 [공통 확정 대상]

중국 선협펑크 계열을 바탕으로 하되 **한국의 동양적 미와 현대적 미를 결합**한다.
결합은 인물과 배경에 역할을 나눠 구현한다.

| 층 | 담당 | 처리 |
|---|---|---|
| 인물 | 현대 | 선이 정리돼 있다. 옷주름을 잘게 그리지 않고 큰 면으로 끊는다 |
| 배경 | 동양 | 수묵 농담과 번짐. 인물보다 밀도가 높다. 여백을 크게 쓴다 |

## 2. 정리 수준 — 인물과 배경 사이의 거리 [공통 확정 대상]

> 인물은 배경보다 **한 단계 정리돼 있다.** 배경만큼 잔질감을 넣지 않되,
> 셀 애니메이션만큼 납작하지도 않다.

- 완전한 셀 명암으로 가면 인물이 배경과 따로 논다.
- 배경과 같은 밀도로 그리면 현대미가 사라지고 전통 삽화가 된다.
- 이 거리는 제작 가능성 수단이기도 하다. 배경은 재사용할 수 있지만 인물은 컷마다 새로 그려야 한다.

## 3. 선 [공통 확정 대상]

- 중국 선협 특유의 유려한 과잉 곡선을 쓰지 않는다.
- **한국식 절제된 곡선 하나 + 직선.** 저고리 배래선의 구조다. 한푸의 흐르는 넓은 소매와 다르다.

## 4. 동양미와 시대감을 바꿔 쓰지 않는다 [공통 확정 대상]

수묵 배경과 전통 재질을 쓰다 보면 도시가 전근대 마을로 그려지는 사고가 난다.
두 요소의 담당을 나눈다.

| 담당 | 무엇으로 들어오는가 |
|---|---|
| **동양미** | 재질과 색: 백자 무광 유약면, 한지 섬유 결, 단청 계열 색, 수묵 농담, 여백 |
| **시대감** | 구조와 설비: 노출 또는 매립된 영기 도관, 계량기, 검침 표식, 등급판, 각인 검문대 |

"낡았다"와 "미개하다"를 혼동하지 않는다. 설비가 낡은 구역도 영기공학 문명 안에 있다.
[기존 캐논 확인] 영기공학은 생활 기반시설이며(`world/overview.md` §4-1·§4-3), 같은 영원 도시 안에서도
구역 간 기술 편차가 크다(`world/overview.md` §4-4 표 기준 주석, `world/cities.md`).

## 5. 한국 쪽으로 당기는 소품 [공통 확정 대상]

레퍼런스나 생성 결과에 일본계 소품이 섞이면 아래로 바꾼다.

| 나오기 쉬운 것 | 인역에서 쓸 것 |
|---|---|
| 시데(紙垂) 달린 신사풍 사당 | 장승·솟대·서낭당 계열, 또는 영기 봉인 표지 기둥 |
| 일본식 삿갓 | 갓·패랭이 계열 (필요할 때만) |
| 급한 처마 곡선 | 한식 기와의 **완만한** 처마 곡선 |
| 순백 | 소색(素色): 약간 누런 흰색 |

## 6. 기본 렌더링 [공통 확정 대상]

- 비사실적. 실사풍이 기본이 아니다.
- 인물에는 중간톤 그라데이션을 쓰지 않는다. 배경의 수묵 농담은 허용한다(층이 다르다).

## 7. 작품마다 정하는 것

비례(등신), 연령 인상, 색 비중, 분위기, 사이버펑크와 선협 소재의 비율은 작품별 작화 문서에서 정한다.
이 문서의 1~6항과 충돌하는 작품 규칙이 필요하면 캐논 승격 리뷰로 올린다.
