## 1. 캐논 정의와의 연결 [기존 캐논 확인]

- 침식은 외부 세계의 고밀도 영기와 정신·정보 오염에 노출되어 의식이 붕괴·변형되고,
  육체가 외부 세계 영기에 의해 재형성되는 현상이다(`world/overview.md` §7-1).
- 육체 변형은 "정보 오염" 경로로, 외부 세계의 존재 설계 정보가 세포·조직 단위 재형성을 일으킨다(§7-2).
- 단계: 1단계는 외관 변화 없음, 2단계 체표 변형 시작, 3단계 원종 형태 부분 소실, 4단계 외부 세계 형태로 재형성,
  5단계 원종 불명(§7-3).

아래 표면 규약은 이 "재형성"을 화면에서 읽히게 하는 방법이다.

## 2. 표면 규칙 [공통 확정 대상]

> 침식은 부패가 아니라 **원래의 결이 사라지고 다른 규칙으로 재구성된 표면**이다.

| 항목 | 규칙 |
|---|---|
| 색 | **거의 검정에 가까운 적갈(黑赤).** 채도를 낮게 유지해 선혈로 읽히지 않게 한다 |
| 질감 | 원래 조직의 결(털·섬유·나뭇결)이 사라지고, **일정한 간격의 얕은 기하 패턴**이 드러난다 |
| 패턴 | **규칙적이다.** 무작위 얼룩이 아니다 |
| 경계 | 또렷하다. 그라데이션으로 번지지 않는다 |
| 발광 | 없음 |
| 돌기·촉수·결정 | 없음. 패턴은 표면 안에 있고 밖으로 자라나지 않는다 |
| 유혈·단면·부패 | 없음 |
| 움직임 | 없음. 정지해 있다. 꿈틀거리지 않는다 |

**붉은 기와 패턴을 같이 쓰는 이유.** 붉은 기만 넣으면 피·괴사로 읽히고, 패턴만 넣으면 결정화로 읽힌다.
둘을 같이 써야 유기물도 상처도 아닌 것이 된다. 패턴이 있다는 사실이 "무언가가 이 표면을 다시 짰다"를
대사 없이 전달한다.

## 3. 초기 침식 개체의 원칙 [공통 확정 대상, 적용 범위 제한]

> 초기 침식은 해부학을 바꾸지 않는다. 상태를 바꾼다.

- 골격·비례·크기·부위 형태는 원종 그대로 둔다.
- 바뀌는 것: 눈의 하이라이트 제거, 표정이 빠짐, 자세·걸음이 일정하고 직선적이 됨, 시선이 관찰자를 지나침,
  침식 경계 주변의 결이 방향성을 잃음.
- 원종과 침식 표면은 **따로 설계해 합성한다.** 같이 고치면 하나를 고칠 때 다른 하나가 흔들린다.

**적용 범위.** 작화 정본의 근거 개체(남육 마수)는 "침식 초기"다. 캐논 §7-3은 3단계부터 원종 형태가
소실된다고 정하므로, 이 원칙은 **1~2단계(체표 변형까지)에만** 적용한다.

## 4. 결정이 필요한 것 [미정]

- **3단계 이상의 시각 규약.** 원종 형태가 무너지고 외부 세계 형태로 재형성되는 단계의 그림은 정해진 적이 없다.
  2부 이후 경계대 시각 규약(작화 정본 V-07)과 함께 정해야 한다.
- **침식 결정·침식 잔편의 시각.** 캐논에는 침식 결정이 자원으로 존재한다(`world/ecology.md`, `world/overview.md` §11-2).
  그런데 표면 규약은 "결정 돌기 없음"이다. 결정이 사체에서 어떻게 나오는지, 표면에 보이는지는 정해지지 않았다.
- **사람의 침식 표면.** 작화 정본은 사체 한 곳(왼팔 아래)에만 적용했다. 살아 있는 사람에게 같은 규약을 쓸지는 미정이다.
