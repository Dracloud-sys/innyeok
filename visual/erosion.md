## 1. 캐논 정의와의 연결 [기존 캐논 확인]

- 침식은 외부 세계의 고밀도 영기와 정신·정보 오염에 노출되어 의식이 붕괴·변형되고,
  육체가 외부 세계 영기에 의해 재형성되는 현상이다(`world/overview.md` §7-1).
- 육체 변형은 "정보 오염" 경로로, 외부 세계의 존재 설계 정보가 세포·조직 단위 재형성을 일으킨다(§7-2).
- 단계: 1단계는 외관 변화 없음, 2단계 체표 변형 시작, 3단계 원종 형태 부분 소실, 4단계 외부 세계 형태로 재형성,
  5단계 원종 불명(§7-3).

아래 표면 규약은 이 "재형성"을 화면에서 읽히게 하는 방법이다.

## 2. 표면 규칙 [운영자 결정 2026-11-28, C-011]

> 침식은 부패가 아니라 **원래의 재질이 반대 계열의 재질로 바뀌는 변화**다.
> 유기물은 무기물로, 무기물은 유기물로 변한다.

| 대상 | 표현 |
|---|---|
| 사람·동물·식물 등 유기체 | 돌·도자기·금속 등 **무기질**을 연상시키는 표면과 질감으로 바뀐다 |
| 구조물·도구·설비 등 무기체 | 섬유·조직·껍질 등 **유기질**을 연상시키는 표면과 질감으로 바뀐다 |

| 항목 | 규칙 |
|---|---|
| 표현 방식 | 장식 무늬를 덧붙이지 않고 **재질 자체의 변화**로 보여 준다 |
| 문양·패턴 | **기본적으로 사용하지 않는다.** 사람·마수·식물·무기체 모두 같다 |
| 색 | 고정 색을 두지 않는다. 바뀐 재질에 따른다 |
| 발광 | 없음 |
| 돌기·촉수·결정 | 표면 밖으로 자라나는 성장물로 단계를 표시하지 않는다 |
| 유혈·단면·부패 | 없음 |
| 움직임 | 바뀐 표면 자체가 꿈틀거리거나 독립적으로 움직이지 않는다 |

- 무기체의 유기질화는 생명이나 자아가 생긴다는 뜻이 아니다. [운영자 결정]
- 무기체 침식은 기존 캐논에 근거가 있다: 침식된 축령정, 진행성 침식 기구, 외역화(`world/architecture.md`). [기존 캐논 확인]
- 대체된 이전 규칙(2026-09-04 작화 정본 기준): 흑적(黑赤) 색, 일정 간격의 규칙적 기하 패턴. 이전 작품 시안에 남아 있어도
  새 작업에는 적용하지 않는다. 어떤 작품에서 의도적으로 문양을 쓰는 것은 작품 설정으로 둔다.

## 3. 초기 침식 개체의 원칙 [공통 확정 대상, 적용 범위 제한]

> 초기 침식은 해부학을 바꾸지 않는다. 상태를 바꾼다.

- 골격·비례·크기·부위 형태는 원종 그대로 둔다.
- 바뀌는 것: 눈의 하이라이트 제거, 표정이 빠짐, 자세·걸음이 일정하고 직선적이 됨, 시선이 관찰자를 지나침,
  침식 경계 주변의 결이 방향성을 잃음.
- 원종과 침식 표면은 **따로 설계해 합성한다.** 같이 고치면 하나를 고칠 때 다른 하나가 흔들린다.

**적용 범위.** 작화 정본의 근거 개체(남육 마수)는 "침식 초기"다. 캐논 §7-3은 3단계부터 원종 형태가
소실된다고 정하므로, 이 원칙은 **1~2단계(체표 변형까지)에만** 적용한다.

## 4. 결정이 필요한 것 [미정]

- **3단계 이상의 시각 규약.** [운영자 결정 2026-11-28, 이슈 #6] 3~4단계는 **원종의 흔적이 남아 있는 방향**으로 표현한다.
  5단계의 "원종 불명"(`world/overview.md` §7-3)은 유지하며, 5단계까지 원종을 알아볼 수 있다는 뜻으로 넓히지 않는다.
  [미정] 단계별 상세 외형·변형 강도, 개별 시안(사슴 비교안 등)의 단계 배정. 개체 시안은 공통 규칙이 아니다.
- **단계별 변형 강도.** 재질 변화가 단계마다 얼마나 넓고 깊어지는지는 정하지 않았다.
- 침식 결정·잔편의 정의는 `world/overview.md` §11-2 주석(2026-11-28 운영자 결정)을 따른다.
  결정이 사체의 어느 부위에서 어떻게 나오는지는 여전히 미정이다.
- 살아 있는 사람의 침식 표면: §2를 그대로 적용한다(2026-11-28 운영자 결정, 문양 기본 미사용).
